# Калькулятор постфиксной нотации

Программа вычисляет выражения, записанные в обратной польской (постфиксной) записи, с помощью стека.

## Быстрый старт

Проект управляется через [uv](https://docs.astral.sh/uv/). Все команды запускаются из папки `postfix_notation`.

| Команда         | Что делает                                           |
|-----------------|------------------------------------------------------|
| `make help`     | показывает список команд                             |
| `make install`  | устанавливает зависимости (`uv sync`)                |
| `make run`      | запускает калькулятор, выражение вводится с клавиатуры |
| `make test`     | запускает тесты с подробным выводом                  |
| `make coverage` | запускает тесты и показывает покрытие кода           |
| `make clean`    | удаляет `.pytest_cache`, `.coverage` и `__pycache__` |

Пример работы:

```
$ make run
Введите выражение, записанное в постфиксной нотации через пробел : 3 4 + 2 *
0: Stack - (3)
2: Stack - (3, 4)
4: Stack - (7)
6: Stack - (7, 2)
8: Stack - (14)
3 4 + 2 * = 14
```

В строке трассировки слева стоит позиция символа в выражении, дальше состояние стека после этого символа.

Если `uv` предупреждает, что `VIRTUAL_ENV` не совпадает с окружением проекта, это безопасно: `uv` использует свой `.venv` в этой папке. Чтобы убрать предупреждение, выполните `deactivate` или `unset VIRTUAL_ENV`.

## Что реализовано

### Класс `Stack`

Стек целых чисел на основе списка `items`.

| Метод          | Описание                                                              |
|----------------|-----------------------------------------------------------------------|
| `push(value)`  | кладёт значение на вершину                                            |
| `pop()`        | снимает и возвращает значение с вершины; на пустом стеке `IndexError` |
| `last_value()` | возвращает вершину, не снимая; на пустом стеке `IndexError`           |
| `size()`       | количество элементов                                                  |
| `sum()`        | сумма всех элементов, для пустого стека `0`                           |
| `__str__()`    | строка вида `Stack - (1, 2, 3)`, для пустого `Stack - ()`             |

### Функция `stack_mashine(expression: str)`

Вычисляет выражение и возвращает результат. Идёт по символам слева направо и пропускает пробелы, поэтому подходят записи `"3 4 +"` и `"34+"`. Числа однозначные, так как строка разбирается посимвольно.

- **Цифра** кладётся на стек.
- **Операция** снимает два верхних значения. Левым операндом считается то, что лежало глубже: `"5 2 -"` даёт `3`, а `"2 5 -"` даёт `-3`.

| Символ | Операция                                                   |
|--------|------------------------------------------------------------|
| `+`    | сложение                                                   |
| `-`    | вычитание                                                  |
| `*`    | умножение                                                  |
| `/`    | деление, результат `float` (`"2 4 /"` даёт `0.5`)          |
| `~`    | особая операция, см. ниже                                  |

**Операция `~`.** Снимает два верхних значения `a` и `b`:

- если оба не равны нулю, кладёт на стек `|a - b|`;
- если хотя бы одно равно нулю, кладёт на стек квадрат суммы того, что осталось на стеке после снятия.

Примеры: `"5 2 ~"` даёт `3`. В `"3 5 0 ~"` снимаются `0` и `5`, остаётся `[3]`, на стек кладётся `9`, и получается `[3, 9]`. Поэтому для одного результата нужна ещё операция, например `"3 5 0 ~ +"` даёт `12`.

### Обработка ошибок

| Ситуация                                         | Исключение          |
|--------------------------------------------------|---------------------|
| выражение не строка                              | `TypeError`         |
| пустая строка или только пробелы                 | `ValueError`        |
| недопустимый символ, например `a`                | `ValueError`        |
| для операции на стеке меньше двух значений       | `ValueError`        |
| в конце на стеке осталось больше одного значения | `ValueError`        |
| деление на ноль                                  | `ZeroDivisionError` |

В сообщениях `ValueError` и `ZeroDivisionError` указана позиция символа в выражении.

## Тесты

Файл [tests/test_main.py](tests/test_main.py), всего 30 тестов, запускаются через `pytest`.

### Класс `TestStack` (фикстура `stack` содержит `1, 2`)

| Тест                  | Что проверяет                                              |
|-----------------------|------------------------------------------------------------|
| `test_stack_creation` | новый стек пуст                                            |
| `test_stack_push`     | после `push(3)` вершина `3`, размер `3`                    |
| `test_stack_pop`      | `pop()` возвращает `2`, вершина становится `1`, размер `1` |
| `test_stack_size`     | размер равен `2`                                           |
| `test_stack_sum`      | сумма равна `3`                                            |

### `test_stack_mashine` (параметризованный, 14 случаев)

| Выражение         | Ожидается | Что проверяет                                              |
|-------------------|-----------|------------------------------------------------------------|
| `7`               | `7`       | одно число                                                 |
| `3 4 +`           | `7`       | сложение                                                   |
| `5 2 -`           | `3`       | вычитание                                                  |
| `2 5 -`           | `-3`      | порядок операндов в вычитании                              |
| `3 4 *`           | `12`      | умножение                                                  |
| `8 2 /`           | `4`       | деление                                                    |
| `2 4 /`           | `0.5`     | порядок операндов в делении                                |
| `3 4 + 2 *`       | `14`      | цепочка операций                                           |
| `1 2 + 5 3 - *`   | `6`       | вложенные операции                                         |
| `5 2 ~`           | `3`       | `~`, разность                                              |
| `2 5 ~`           | `3`       | `~`, порядок не важен                                      |
| `4 4 ~`           | `0`       | `~`, равные числа                                          |
| `3 5 0 ~ +`       | `12`      | `~` с нулём, затем сложение                                |
| `5 2 ~ 4+`        | `7`       | результат `~` в дальнейших вычислениях, запись без пробела |

### `test_stack_mashine_errors` (параметризованный, 8 случаев)

| Выражение   | Исключение          | Причина                  |
|-------------|---------------------|--------------------------|
| `""`        | `ValueError`        | пустое выражение         |
| `+`         | `ValueError`        | нет операндов            |
| `1+`        | `ValueError`        | один операнд             |
| `~`         | `ValueError`        | нет операндов для `~`    |
| `1 ~`       | `ValueError`        | один операнд для `~`     |
| `1 2 a +`   | `ValueError`        | недопустимый символ      |
| `1 2 3 +`   | `ValueError`        | лишний операнд           |
| `5 0 /`     | `ZeroDivisionError` | деление на ноль          |

### `test_stack_mashine_rejects_non_string` (параметризованный, 3 случая)

Входы `None`, `123` и `["3", "4", "+"]` приводят к `TypeError`.
