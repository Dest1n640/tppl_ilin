# Выбор парадигмы и языка программировани

### 1. Обработка больших данных в реальном времени

- Парадигма - императивное + параллельное программирование
- Язык программирования: C++/Rust.
- Обясненеие: Языки хорошо справляются с обработкой изображение(OpenCV в С++). Компиляции в машинный код дает хорошую скорость, что важно для работы с таким большим количеством изображений. Так же, в языках есть готовые, быстрые математические библиотеки

### 2.Прототип ML-сервиса для прогноза погодных условий

- Парадигма - императивное / объектно-ориентированное
- Язык программирования: Python
- Обоснование: Огромная готовая экосистема ML-библиотек и динамическая типизация позволяют быстро писать и переписывать код — что критично при MVP за 2 недели.

### 3. Интерактивный UI для торгового терминала

- Парадигма - Реактивное программирование
- Язык программирования: JavaScript / TypeScript (с библиотекой React)
- Объяснение: React нужен, что бы при изменении состояния виджеты обновляются автоматически, что и нужно для 50+ взаимосвязанных виджетов. React это допускает благодаря своему реактивному подходу. 

### 4. Прошивка для устройства регистрации температуры

- Парадигма - Императотивное программирование
- Язык программирования: C
- Объяснение: Прямой доступ к регистрам, компиляции под разные архитектуры, отсутствие GC — важно при 32KB RAM и работе от батареи с детерминированным откликом.
