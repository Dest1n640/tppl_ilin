# Токенизатор

Программа читает исходный код из файла в кодировке UTF-8 и выводит токены.

## Установка

Перейдите в директорию `tokenizer` и установите зависимости:

```bash
make install
```

Команда выполняет `uv sync` и устанавливает зависимости из `pyproject.toml`.

## Команды Makefile

Все команды выполняются из директории `tokenizer`:

```bash
make help            # Показать справку
make install         # Установить зависимости через uv sync
make test            # Запустить тесты
make coverage        # Запустить тесты и показать покрытие main.py
make run input.txt   # Запустить токенизатор для указанного файла
```

Команда `make` без аргументов показывает справку.

## Запуск

Выполните команду из директории `tokenizer`, передав путь к исходному файлу:

```bash
make run input.txt
```

Каждый токен выводится в формате `(<тип>, <значение>, <строка>:<столбец>)`.
Строки и столбцы считаются с 1 и указывают на начало токена.
Символ табуляции занимает один столбец.

Поддерживаются идентификаторы, ключевые слова `if`, `else`, `while`, `return`,
`for`, `def`, целые и вещественные числа, строки в двойных кавычках,
операторы `+ - * / = < > == <= >=` и разделители `( ) { } , ;`.
Пробелы, табуляция, переводы строк и комментарии от `#` до конца строки пропускаются.

## Ошибки

Для файла `invalid.txt` с содержимым `a @ b`:

```bash
make run invalid.txt
```

Токенизатор выводит в stderr:

```text
invalid.txt:1:3: lexical: unexpected character '@'
```

При лексической ошибке или ошибке чтения файла код завершения равен 1.
При успешном выполнении — 0.
При неудачном запуске make также выводит сообщение об ошибке цели `run`.

## Тесты

Запуск тестов на pytest:

```bash
make test
```

Запуск тестов с отчётом о покрытии `main.py`:

```bash
make coverage
```
